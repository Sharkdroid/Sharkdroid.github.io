Tool knowledge The `claude mcp add` CLI command has three distinct scopes that are easy to conflate: `user` scope stores entries at the top level of `~/.claude.json` under `mcpServers` and applies across all projects; `local` scope (the CLI's actual default, not `project`) stores entries under `projects.<project-path>.mcpServers` within the same `~/.claude.json` file and is scoped to one project without being committed to version control; `project` scope writes to a separate `.mcp.json` file in the project directory, intended for team-shared configuration and typically committed to git. The CLI accepts environment variables via repeated `-e KEY=value` flags before the `--` separator, followed by the command and its arguments (e.g., `claude mcp add cascade-cms -s user -e CASCADE_API_KEY=xxx -e CASCADE_URL=xxx -- uvx --no-cache cascade-cms-rest-mcp`).
