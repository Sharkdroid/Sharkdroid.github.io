# Maintenance

This section will document the automated GitHub Actions workflow that keeps the library up to date with new Cascade CMS API versions and regenerates the SKILL file.

**Status: Not yet implemented.**

---

## Planned: Auto-Update Workflow

When implemented, this workflow will:

- Detect new Cascade CMS REST API versions
- Update library operation signatures and payload models to match
- Regenerate the SKILL file snapshot from the updated source
- Open a pull request with a change summary and test results
- Update this wiki section with changelog entries

The workflow will be triggered on a schedule (weekly), manually via `workflow_dispatch`, or on API change detection.

**Files involved (when ready):**

| File | Purpose |
|------|---------|
| `.github/workflows/auto-update.yml` | Workflow definition |
| `src/cascade_cms/` | Library source (updated by the workflow) |
| `.skill/` | SKILL file (regenerated by the workflow) |
| `CHANGELOG.md` | Updated with each auto-update PR |

---

## Current: Manual Update Process

Until the auto-update workflow exists, updates are applied manually:

1. Review the [Cascade CMS REST API changelog](https://www.hannonhill.com/cascadecms/latest/developing-in-cascade/rest-api/index.html) for new or changed endpoints
2. Update operation signatures in `operations.py`
3. Update or add payload/response models in `cmstypes.py`
4. Update the SKILL file snapshot in `.skill/` to reflect the changes
5. Increment the version in `pyproject.toml`
6. Update `CHANGELOG.md`
7. Run tests and publish

---

## SKILL File

The SKILL file at `.skill/` in the [source repository](https://github.com/<your-org>/<your-repo>) enables AI-assisted script generation for this library. It is a snapshot of the library's source files bundled with a generation spec and prompt.

When the library changes, the SKILL file must be updated to reflect the new source. The planned auto-update workflow will handle this automatically; until then, update it manually alongside library changes.

See the repository README for instructions on using the SKILL file with supported AI coding assistants.
