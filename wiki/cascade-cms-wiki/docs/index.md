# Operations Reference

Complete reference for every operation available on `cascade.operations`. Operations are grouped by category.

- **[Operations](./operations/operations.md)** — CRUD, search, publishing, workflow, access control, audit, messaging
- **[CMS Types](./operations/cmstypes.md)** — Enums and constants for Cascade content types
- **[Wrapper](./operations/wrapper.md)** — The `cascade` entry point tying driver, operations, and logger together
- **[Driver](./operations/driver.md)** — Low-level HTTP/session handling
- **[Operation Logger](./operations/operation_logger.md)** — Structured logging for operations and callback chains
